# Contributing to TextGraph for Markdown

Use the [shared issue tracker](https://github.com/drawmotive/textgraph/issues)
for Markdown, VitePress and VS Code preview issues. Include the product/version,
OS, Node/npm or VS Code version, expected behavior and a small Markdown example.

The root npm plugin supports Node.js 22.12+ on the 22 line or Node.js 24,
with npm 10 or 11 on Linux, Windows and macOS. The independent VSIX build
supports Node 22 or 24. Installed extension users use VS Code's own Node host.
See the [plugin](README.md#requirements) and
[extension](vscode/README.md#requirements) support boundaries.

From a standalone public checkout, verify the npm plugin:

```bash
npm ci
npm test
npm run build
npm pack
```

For changes to generated pages or integration behavior:

```bash
npx playwright install chromium
npm run test:browser
```

The root delivery is an npm archive. Its renderer comes from the exact public
SDK in the registry lock; no private C# or WASM producer build is needed.

The VS Code extension is a separate npm project with a separate lockfile.
Run these commands from `vscode/`:

```bash
npm ci --workspaces=false
npm test
npm run build
npm run package
npm run test:host
```

It is delivered as a VSIX, not an npm product. Local packaging does not
publish. `release:check` and publish commands retain coordinated release
eligibility checks, including deferred releases. Host tests download VS Code
and use isolated profiles; Linux needs a display or
`xvfb-run -a npm run test:host`. Browser tests of the root plugin do not replace
the real Extension Host checks.

Use the public committed locks with `npm ci`. Change dependencies intentionally
with `npm install` and commit the corresponding lock. Do not replace registry
dependencies with local paths or workspace links. Preserve runtime integrity
and provenance rather than editing generated bytes to bypass checks.

Keep pull requests focused, add a regression for behavior fixes and report
only checks actually run. Review commands and links for documentation changes.
Retain [LICENSE](LICENSE), [vscode/LICENSE](vscode/LICENSE) and the dependency
and font terms indexed in [NOTICE](NOTICE).
