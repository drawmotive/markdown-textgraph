# Security reporting

This policy covers the Markdown/VitePress npm plugin and the separate VS Code
Markdown Preview extension in this repository. Identify the affected product,
version, OS, Node/VS Code version, a minimal reproduction and expected impact.
Remove secrets and unrelated private Markdown source from reports.

GitHub private vulnerability reporting is enabled. Use
[Report a vulnerability](https://github.com/drawmotive/markdown-textgraph/security/advisories/new)
to submit a private report. Do not post exploit details publicly.

Use the [shared issue tracker](https://github.com/drawmotive/textgraph/issues)
for ordinary bugs and support questions without sensitive details.
