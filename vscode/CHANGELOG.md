# Changelog

## 0.3.5

- Bundle the TextGraph SDK 0.3.5 for local Markdown Preview rendering and diagnostics.
- Require VS Code 1.105 or newer for the bundled WebAssembly runtime.
- Highlight TextGraph fences, including named nodes and connection operators.

## 0.2.1

- Bundle public TextGraph SDK 0.2.1 with scale-one PNG defaults and logical display dimensions.
- Retain local Markdown Preview rendering, inline diagnostics, and Restricted Mode support.

## 0.2.0

- Bundle public TextGraph SDK 0.2.0 with inline-group rendering and parser recovery fixes.
- Verify successful empty and nested group rendering in installed Markdown Preview.

## 0.1.0

- Live TextGraph diagrams and inline diagnostics in built-in Markdown Preview.
- Local public SDK rendering in a cancellable Node Worker and Restricted Mode support.
- Bundled runtime assets and installed-VSIX Extension Host tests.
